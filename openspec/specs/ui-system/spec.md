# Capability: Luxury Vercel Dark UI System

## Overview
Mind Forensics adheres to a strict luxury dark design standard with precision hairline borders, high-contrast typography, and living secondary color accents.

## Requirements

### Requirement: Dark Mode Architecture
- Ground Level: Pure pitch black `#000000` (OLED).
- Surface Level 1: Deep neutral `#0A0A0A` with 1.0px hairline border `#222222`.
- Corner Radii: Strict `8.0px` to `10.0px`.
- High-contrast text: `#EDEDED` (primary) and `#888888` (muted secondary).

### Requirement: Secondary Color Suite
The system SHALL incorporate three luxury secondary color accents:
1. **Cherry Red** (`#E11D48`, dark bg `#22080F`, border `#4C1020`): Denotes active deconstruction, physical arousal, and emergency response.
2. **Warm Beige / Cashmere** (`#E7D8C9`, dark bg `#1B1713`, border `#382F26`): Denotes grounded cognitive reframing, somatic equilibrium, and editorial insight.
3. **Sage Green** (`#34D399`, dark bg `#092419`, border `#134E37`): Denotes parasympathetic recovery and completed cognitive sessions.

### Requirement: No Emoji Directive
Emojis are strictly prohibited across all buttons, chips, app bars, dialogs, and badges. All iconography MUST use minimal vector outline icons (`Icons.*_outlined`) or clean typographic tags.
